# LinealAlRL

Álgebra lineal en el navegador: matrices con pasos, sistemas lineales directos e
iterativos, valores propios y condicionamiento. Hecho en Reox Lab.

- **Ruta:** `/herramientas/linealalrl/`
- **Stack:** TypeScript, Vite, KaTeX, rl-ui, Nginx + Docker
- **Licencia:** GPL v3 (`GPL-3.0-or-later`)

## Desarrollo local

Requisitos: Node.js 20+.

```bash
npm install
npm run dev      # servidor local de desarrollo
npm test         # pruebas unitarias
npm run build    # verificación de tipos y paquete de producción en dist/
```
